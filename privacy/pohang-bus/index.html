포항버스 정보 개인정보처리방침

시행일: 2026년 10월 18일

이 방침은 Android 앱 포항버스 정보(패키지명: com.DGY.Pohuang.Bustable)의 정보 처리에 관한 안내입니다. Google Play에 표시된 개발자명은 연정아이며, 앱 지원 이메일은 carpediem.jun7@gmail.com입니다. 이 방침은 해당 패키지에만 적용되며 다른 지역 앱의 개인정보처리방침을 변경하지 않습니다.

1. 버스 정보 검색과 기기 내 저장

앱은 버스 노선·정류장·도착 정보와 지도를 제공하기 위해 공개 버스 데이터를 이용합니다. 일반 포항 화면의 노선·정류장 검색어는 기기에 저장된 데이터베이스에서 검색에 사용됩니다. 이 검색 과정에서 입력한 검색어를 서버에 전송하거나 최근 검색 기록으로 저장하는 기능은 없습니다. 버스 데이터를 불러오거나 갱신하는 통신은 검색어 처리와 별도로 이루어질 수 있습니다.

즐겨찾기에는 선택한 노선의 식별자·번호, 기종점명, 첫차·막차 정보 등이 저장됩니다. 노선·정류장 데이터, 정류장 좌표, 갱신 시각 및 공개 설정 정보도 기기의 앱 전용 저장소에 저장됩니다. 이는 검색, 즐겨찾기 표시, 데이터 재사용과 갱신을 위한 정보입니다.

앱 자체의 회원가입·로그인 기능이나 기기의 GPS 위치를 요청하는 기능은 제공하지 않습니다. 지도에 표시하거나 외부 지도에 전달하는 좌표는 선택한 공개 정류장의 좌표이며, 사용자의 현재 위치가 아닙니다. 다만 광고 서비스가 IP 주소로 대략적인 지역을 추정하는 등의 처리는 아래 광고 서비스 안내와 구분됩니다.

2. 버스 데이터·설정·지도 서비스와 통신

앱의 기능에 따라 다음 서비스에 요청이 전달됩니다. 인터넷 요청을 받는 서비스는 IP 주소와 요청 시각 등 접속에 필요한 정보를 확인하거나 기록할 수 있습니다. 서비스별 기록의 이용·보관·삭제는 해당 제공자의 정책과 운영 방식에 따르며, 앱의 기기 내 데이터 삭제와는 별개입니다.

  • 포항 버스 정보 조회: 노선·정류장·도착·버스 위치 정보를 확인할 때 TAGO 공공 버스 API (apis.data.go.kr)에 공개 도시·노선·정류장 식별자 등 조회 매개변수를 전달합니다. 전송 방식은 HTTP입니다.
  • 공개 설정 정보 확인: GitHub Pages (junhyuk.github.io)에 공개 설정 파일을 요청합니다. 전송 방식은 HTTPS입니다.
  • 앱 내 노선 지도: unpkg.com에서 Leaflet 지도 표시 파일을 불러오고, OpenStreetMap (tile.openstreetmap.org)에 표시할 지도 영역의 타일을 요청합니다. 두 요청 모두 HTTPS입니다.
  • 사용자가 선택한 외부 지도: 네이버 지도 앱 또는 웹에 선택한 정류장명·공개 정류장 좌표 등을 전달합니다. 일반 포항 화면의 웹 연결은 HTTPS이며 외부 지도 앱을 열 수도 있습니다.

패키지에 남아 있는 이전 화면: 이전 포항 화면은 안동 버스 서비스 (bus.andong.go.kr)에 노선·정류장·도착 정보와 시간표를 요청하며, 영주 참조 화면은 TAGO에 조회합니다. 안동 API와 TAGO는 HTTP, 안동 시간표는 HTTPS입니다. 일부 이전 화면에서 사용자가 외부 지도를 선택하면 카카오 지도에 노선번호를 포함한 버스 검색 문구를, 네이버 지도에는 정류장명·좌표를 전달합니다. 카카오 웹 연결은 HTTPS이며 이전 네이버 웹 지도에는 HTTP 경로가 있습니다.

이전 화면은 같은 앱 패키지에 포함되어 있습니다. 일반 시작 화면에서는 열리지 않지만, 다른 앱이 해당 화면을 직접 열도록 요청하면 실행될 수 있습니다. 위 안내는 이 패키지에 포함된 경로에 관한 것이며, 별도로 배포되는 안동·영주 앱에 관한 방침이 아닙니다.

외부 지도를 열면 해당 지도 앱 또는 브라우저로 이동합니다. 이후 외부 서비스가 자체적으로 처리하는 정보와 선택 사항은 해당 서비스의 정책과 설정을 확인해 주세요.

3. 광고 서비스

앱에는 Google AdMob 배너 광고가 있으며, Google Mobile Ads SDK 24.4.0이 포함되어 있습니다. 광고를 요청하고 표시하는 과정에서 Google의 광고 서비스는 IP 주소, 광고와 앱 이용 관련 상호작용, 진단 정보, 광고 ID 등 식별자를 처리할 수 있습니다. 이러한 정보는 광고 제공, 분석 및 부정 사용 방지 등 서비스 목적에 이용될 수 있습니다. IP 주소로 대략적인 지역이 추정될 수 있으며, 이는 앱이 GPS 위치를 가져온다는 의미가 아닙니다.

광고 ID 이외의 식별자가 처리되는 경우 목적은 식별자 종류에 따라 다를 수 있습니다. 예를 들어 앱 세트 ID는 분석·부정 사용 방지와 같은 비광고 목적을 위한 식별자이며, 개인화 광고를 위한 ID로 설명하지 않습니다. 광고 관련 처리의 자세한 내용과 선택 사항은 Google 개인정보처리방침과 Google 광고 안내를 확인해 주세요.

Android의 광고 관련 설정에서 광고 ID 및 제공되는 개인정보 보호 선택 사항을 관리할 수 있습니다. 메뉴와 지원 기능은 Android 버전에 따라 다릅니다. 광고 ID를 삭제하거나 제한하는 것만으로 광고 표시 또는 광고 서비스의 모든 정보 처리가 중단되는 것은 아닙니다.

4. 선택적인 Firebase 사용 분석과 오류 진단

이 절은 패키지 com.DGY.Pohuang.Bustable의 Firebase Analytics 및 Crashlytics 연동이 포함된 첫 Google Play 버전부터 적용됩니다. 사용 분석과 오류 진단 공유는 각각 기본적으로 꺼져 있으며 앱의 개인정보 설정에서 별도로 선택하거나 철회할 수 있습니다. 두 선택은 기존 광고 설정과 별개이며, 거부해도 앱의 기본 기능을 이용할 수 있습니다.

사용 분석이 허용되면 Google Analytics for Firebase가 앱 실행·세션, 앱/기기 정보, 앱 인스턴스 식별자와 IP 주소에서 추정한 대략적인 지역 등을 처리할 수 있습니다. 앱이 추가하는 이벤트는 정해진 이름과 고정된 분류값으로 제한합니다. 자유 입력 검색어, 노선·정류장 상세 ID, 즐겨찾기 내용, 정확한 GPS 위치, URL, 이름, 이메일, 전화번호 또는 사용자 계정 ID를 Firebase 이벤트 값으로 보내지 않습니다. Firebase 광고 ID 수집은 비활성화하고 Firebase 광고 저장소·광고 사용자 데이터·광고 개인 최적화 동의는 거부 상태로 둡니다. 이 설정은 위에서 설명한 AdMob 처리 범위를 바꾸지 않습니다.

Crashlytics는 오류 시점의 스택 추적, 앱 상태와 버전, 운영체제·기기 정보, 설치 식별자 및 관련 세션 진단 정보를 처리할 수 있습니다. 보고서는 오류 진단 공유가 꺼져 있어도 기기에 임시 저장될 수 있으며 자동 전송은 꺼져 있습니다. 진단 공유를 별도로 허용하고 저장된 이전 동의와 보고서 상태가 전송 조건을 충족하는 경우에만 앱이 전송을 요청합니다. 허용된 이전 동의를 확인할 수 없는 보고서는 전송하지 않고 삭제를 요청합니다. 진단 공유를 켰다고 모든 기존 보고서가 곧바로 전송되는 것은 아닙니다.

철회하면 앱은 새 앱 정의 분석 이벤트 전송 요청을 차단하고 Analytics에 수집 중지와 동의 거부를 요청합니다. 진단 공유를 끄면 이후 공유 조건을 닫고 미전송 보고서 삭제를 요청합니다. SDK 내부 처리 또는 이미 시작된 네트워크 전송을 즉시 취소하거나 삭제·전송 완료를 확인할 수는 없습니다. 이미 요청된 전송은 철회 뒤에도 완료될 수 있습니다. 선택과 미전송 보고서는 기기에 저장될 수 있으며, Android 앱 데이터 삭제나 앱 삭제가 이미 Google에 전달된 정보까지 삭제하거나 진행 중인 전송을 취소한다고 보장하지 않습니다.

Firebase 정보의 보관과 삭제는 관련 Google 서비스 정책과 실제 설정에 따릅니다. 이 정책은 확인되지 않은 보관 기간이나 서버 정보의 삭제 완료를 약속하지 않습니다. 상세 설명은 공통 Firebase 추가 고지 및 Firebase 개인정보 안내를 확인해 주세요.

5. 저장·백업과 전송 보호

즐겨찾기와 검색용 버스 데이터는 앱 전용 설정 저장소와 데이터베이스에 저장됩니다. Android의 앱 접근 제한이 적용되는 저장소이지만, 앱이 별도의 암호화 저장을 보장하는 것은 아닙니다.

이 앱은 Android 백업을 허용합니다. 기기·운영체제·사용자의 백업 설정에 따라 앱 설정과 데이터베이스 등이 클라우드 백업 또는 다른 기기로의 데이터 이전에 포함될 수 있습니다. 따라서 앱 데이터가 항상 한 기기에만 남는다고 보장하지 않습니다. 백업의 관리와 삭제는 Android 및 사용 중인 백업 서비스의 설정을 확인해 주세요.

공개 설정과 일반 포항 지도 파일·타일 요청은 HTTPS를 사용하지만, TAGO와 일부 이전 화면의 API·지도 요청은 HTTP를 사용합니다. HTTP 요청은 전송 중 암호화되지 않으므로, 앱의 모든 통신이 암호화된다고 안내하지 않습니다.

6. 보관과 삭제

기기에 저장된 즐겨찾기·설정·버스 데이터는 사용자가 변경하거나 앱이 데이터를 갱신할 때 바뀔 수 있으며, 삭제하지 않은 데이터는 앱 저장소에 남을 수 있습니다. 버스 데이터의 갱신 주기는 개인정보의 삭제 기한을 의미하지 않습니다.

즐겨찾기를 해제하면 현재 표시하는 즐겨찾기 목록에서 해당 노선이 제거됩니다. 다만 이전 버전에서 저장한 즐겨찾기 원본 데이터(CSV 형식)는 앱 저장소에 남을 수 있으므로, 즐겨찾기 해제가 해당 노선에 관한 모든 저장 기록을 지우는 것은 아닙니다.

기기에 남은 앱 데이터를 삭제하려면 Android 설정에서 이 앱의 저장공간 메뉴에 있는 데이터 삭제 / 저장공간 비우기 기능을 이용할 수 있습니다. 제조사와 Android 버전에 따라 메뉴 이름이 다르며, 캐시 삭제만으로는 즐겨찾기 등 앱 데이터가 모두 삭제되지 않습니다. 데이터를 삭제하면 즐겨찾기와 설정도 초기화되고, 다시 실행할 때 버스 데이터가 새로 내려받아질 수 있습니다.

앱을 삭제하거나 기기의 앱 데이터를 지워도 이미 만들어진 Android 백업, 외부 지도 서비스의 기록, 광고 서비스 또는 다른 요청 대상 서버의 기록까지 함께 삭제되는 것은 아닙니다. 백업과 외부 서비스의 정보는 해당 제공자의 삭제·보관 안내를 확인해 주세요.
