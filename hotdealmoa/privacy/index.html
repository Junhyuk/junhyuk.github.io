핫딜모아 개인정보처리방침

최종 업데이트: 2026-07-07

1. 기본 원칙

핫딜모아는 할인 정보와 인기 게시글을 편리하게 조회할 수 있도록 제공되는 앱입니다. 앱은 회원가입이나 로그인 기능 없이 사용할 수 있도록 설계되었으며, 사용자가 직접 입력하는 개인정보를 기본적으로 요구하지 않습니다.

2. 수집하거나 처리할 수 있는 정보

  • 앱 사용 중 필요한 최소한의 기술 정보(기기 정보, OS 버전, 접속 로그, IP 주소 등)가 서비스 안정화 또는 외부 웹페이지 연결 과정에서 처리될 수 있습니다.
  • 광고 SDK 또는 외부 웹 콘텐츠를 사용하는 경우, 광고 제공 또는 페이지 표시를 위해 쿠키 유사 정보, 기기 식별자, 사용 환경 정보가 제3자에 의해 처리될 수 있습니다.
  • 즐겨찾기/설정 등 일부 정보는 사용자 기기 내부 저장소에 로컬로 저장될 수 있습니다.

3. 정보 이용 목적

  • 앱 기능 제공 및 화면 표시
  • 외부 링크 및 원문 페이지 연결
  • 서비스 안정성 유지, 오류 확인 및 개선
  • 광고가 포함된 경우 광고 제공 및 부정 이용 방지

4. 제3자 제공 및 외부 서비스

앱은 원문 게시글, 쇼핑몰 링크, 외부 웹페이지로 사용자를 연결할 수 있습니다. 외부 사이트에서의 개인정보 처리 방식은 각 사이트의 정책을 따릅니다. 또한 광고 SDK, 분석 도구, 웹 콘텐츠 제공자가 자체적으로 정보를 처리할 수 있습니다.

5. 보관 및 삭제

앱 자체가 회원 정보를 별도로 보관하지 않는 것을 원칙으로 합니다. 로컬에 저장된 설정/즐겨찾기 정보는 앱 삭제 시 함께 삭제될 수 있습니다. 외부 서비스가 처리하는 데이터의 보관 기간은 해당 서비스 정책에 따릅니다.

6. 아동의 개인정보

본 앱은 아동을 대상으로 특별히 설계된 서비스가 아니며, 고의로 아동의 개인정보를 수집하지 않습니다.
